# 캐릭터 특징 자동 수집 및 저장 시스템
---

## 목적
---
사용자가 애니/게임 캐릭터의 이름 또는 특정 특징(예: '여우귀', '핑크색 머리')으로 검색하면,
인터넷에서 해당 정보를 자동 수집하고 요약하며, 사용자 검토(RUD)를 거쳐 Markdown 파일로 저장할 수 있는 도구를 만든다.

## 주요 기능
---
1. **캐릭터 이름으로 검색**
   - 나무위키, wikipedia 등에서 캐릭터 정보를 자동 수집
   - 외형, 성격, 출신 배경 등 주요 특징 추출

2. **특징으로 캐릭터 검색**
   - ‘핑크색 머리’, ‘여우귀’ 같은 특징 기반으로 캐릭터 후보 추천
   - 크롤링된 DB나 검색 결과에서 필터링

3. **정보 요약 및 정리**
   - LLM(GPT 등)을 이용해 간결하게 요약
   - 항목별 Markdown 템플릿으로 구조화

4. **사용자 검토(RUD) 기능**
   - 자동 생성된 내용을 사용자가 수정, 삭제, 보완 가능
   - UI 기반 에디터 제공 또는 텍스트 기반 검토

5. **저장 기능**
   - Obsidian 호환 `.md` 포맷 저장
   - 태그 및 링크 구조 지원
   - JSON으로도 저장 가능 (선택적)

## 기술 스택 제안
---
- 백엔드: Python (FastAPI / Flask)
- 프론트엔드: Streamlit (MVP) → React (확장 시)
- 크롤링: requests, BeautifulSoup, Wikipedia API, Google Custom Search API
- 요약: OpenAI GPT, Claude API, 또는 로컬 모델
- 저장: Markdown + 태그 기반 파일 시스템
- 검색: keyword index (Whoosh / SQLite / ElasticSearch 등 선택)

## 타겟 사용자
---
- 캐릭터 정보를 정리하는 위키 운영자
- 창작 캐릭터와 비교 분석하려는 작가/창작자
- 모에 요소 기반 캐릭터를 탐색하려는 팬/연구자

## 우선순위
---
- [1] 캐릭터 이름 기반 검색 및 요약
- [2] 사용자 검토 및 Markdown 저장
- [3] 특징 기반 캐릭터 검색
- [4] 태그 기반 검색 및 관리
